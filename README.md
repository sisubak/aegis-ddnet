## О проекте

Форк DDNet (версия сервера 20.2), переработанный под защиту от DDoS-атак. Основная работа вынесена в сетевой слой: паразитный трафик отсеивается и лимитируется на входе, до того как запросы доходят до игровой логики. Проект находится в стадии альфа-тестирования.

prod by claude 5 opus + claude 4.8 opus

## Возможности

- Фильтрация входящего трафика на сетевом уровне
- Ограничение частоты запросов (rate-limit)
- Баны и блокировки на сетевом уровне
- Captcha-сервер (gate) — отсеивает ботов до входа на игровой сервер
- Защита econ от перебора пароля (бан по IP при исчерпании попыток)
- Фильтр HTTP-запросов против SSRF (блок приватных и loopback-диапазонов)
- Проверка версии через GitHub с предупреждением rcon-админам о новом релизе

## Captcha-сервер

Отдельный gate-сервер, через который проходят все новые игроки перед попаданием на игровой сервер.

Как работает:

- Игроки встают в очередь, капча решается по одному игроку за раз
- Активному игроку показывается лазерная коробка с цифровым кодом, ответ вводится в чат
- Внутри коробки нулевая гравитация и программная коллизия по границам — выйти за пределы капчи нельзя
- При верном ответе игрок редиректится на игровой порт, его адрес добавляется в вайтлист через IPC между gate и игровым сервером
- При неверном ответе или истечении таймера — кик
- Лобби-карта генерируется процедурно, отдельный файл-заготовка не нужен

## Проверка версии

Сервер периодически (при старте и раз в час) обращается к GitHub за списком тегов релизов. Если доступна более новая версия, чем указанная в `sv_version_current`, всем залогиненным в rcon администраторам показывается бродкаст с предупреждением, пока они не разлогинятся или не выйдут.

Конфиг:

- `sv_version_check` — включить/выключить проверку (по умолчанию 1)
- `sv_version_check_url` — URL с тегами релизов (по умолчанию репозиторий проекта)
- `sv_version_current` — тег текущей сборки для сравнения

## В разработке / сырое

- IPC между gate и игровым сервером работает через файл-вайтлист и локальный порт — привязано к одной машине, для разнесённых серверов пока не годится
- Нет защиты от повторного/массового прохождения капчи (rate-limit самих попыток, привязка к сессии)
- Визуал капчи простой: цифры из лазерных сегментов, без искажений против OCR-ботов
- Часть параметров (размер коробки, тайминги) не вынесена в конфиг и требует пересборки для тонкой подстройки; число цифр настраивается через `sv_captcha_srv_digits`
- Тесты на капча-логику не написаны, проверка пока ручная

## Статус

Проект находится в стадии альфа-тестирования (текущий релиз v3b6, база DDNet 20.2). Часть конфигов временные и могут быть неполными, поведение сервера может меняться без предупреждения.
