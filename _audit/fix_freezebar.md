# fix_freezebar.md — Issue #9578 (freezebar не показывается в kill-тайле после финиша)

Проект: DDNet (C++), C:\Users\WWWWWUeHaA\Desktop\antiddos

## Симптом
Тич в команде стоит в kill-тайле (TILE_DEATH) после финиша. Обычно kill-тайл
убивает/фризит, и freezebar показывается. Но при уже финишировавшей команде тич
НЕ умирает и НЕ фризится, при этом freezebar тоже не отображается.

## Анализ реального кода
CCharacter::HandleSkippableTiles (character.cpp:1474-1509) обрабатывает
death-тайлы:
- Условие входа (1477-1485): любой из 8 замеров даёт TILE_DEATH И
  `!m_Core.m_Super && !m_Core.m_Invincible && !(Team() && Teams()->TeeFinished(...))`.
- Ключевой фрагмент: `!(Team() && Teams()->TeeFinished(m_pPlayer->GetCid()))`
  — если игрок в команде (Team() != 0) и уже финишировал, весь блок death-тайла
  ПРОПУСКАЕТСЯ. Тич не умирает, не фризится (character.cpp:1485).
- Внутри блока: при practice — Freeze() (1489), иначе Die() (1500).

Таким образом для финишировавшего командного тича в kill-тайле не вызывается ни
Die(), ни Freeze() — m_FreezeTime остаётся 0, поэтому и freezebar (снап
m_FreezeEnd, character.cpp:1343) равен 0 и не рисуется. Поведение "не умирает"
намеренное (чтобы финишировавшие не гибли на общей kill-линии), но визуально
пользователь ждёт хотя бы freezebar/заморозку.

## Корень
Ветка исключения финишировавших командных тичей из death-тайла
(character.cpp:1485) выключает и заморозку, из-за чего freezebar пуст. Ожидание
из issue: показывать freezebar (или фризить) даже когда смерть подавлена.

## Кандидат-фикс (НЕ применён)
Разделить логику: при подавлении Die() для финишировавшего командного тича
всё равно вызывать Freeze() (как в practice-ветке), чтобы m_FreezeTime > 0 и
freezebar рисовался. Ориентировочно — вынести Freeze() из-под условия исключения:

```
если (в death-тайле) и не super/invincible:
    если Team() && TeeFinished(): Freeze();  // не умираем, но фризимся
    иначе если practice: Freeze() + эффекты
    иначе: Die()
```

Риск: касается gameplay/визуала командного финиша, может изменить ожидаемое
поведение на популярных картах (финишировавшие сейчас свободно ходят по kill-
линии). Нужна проверка на реальных командных картах. Поэтому не применяю.
